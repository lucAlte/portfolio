RideDeck

Transformer un home trainer classique en séance guidée, sur PC comme sur iPad.

Ouvrir RideDeck (nouvel onglet)
Rôle
Conception et développement
Supports
PC et iPad
Statut
En ligne

Le problème

Mon home trainer, un In’Ride 100, n’est pas connecté : la résistance se règle à la main, et rien ne guide la séance ni ne garde l’historique des sorties.

Pourquoi ce projet

Partir d’un besoin réel, le mien, et livrer un produit complet : intégration matérielle, comptes, données synchronisées et site vitrine. Sans budget matériel : toute la valeur vient du logiciel.

Ce que fait RideDeck

  • Indique le niveau de résistance à régler selon la pente du parcours.
  • Affiche en direct la fréquence cardiaque et les données du capteur Bluetooth.
  • Synchronise l’historique des sorties sur tous les appareils, avec création de compte et connexion.
  • Fonctionne sur PC et sur iPad, via le navigateur Bluefy compatible Web Bluetooth.

Technos

  • HTML
  • CSS
  • JavaScript
  • Web Bluetooth API
  • Supabase Auth
  • Supabase Postgres
  • GitHub Pages
  • Bluefy (iPad)

Aucune installation : une page web qui dialogue directement avec les capteurs.

Rivet

Ma version d’un SaaS façon Monday.com, reconstruite de zéro pour la gestion des interventions de techniciens.

Ouvrir Rivet (nouvel onglet)
Rôle
Conception et développement
Pour
Équipes SAV terrain
Statut
En ligne

Le point de départ

Chez Lefort, j’ai intégré Monday.com et n8n pour suivre les interventions SAV. Monday est un outil généraliste : il faut le configurer pour qu’il parle le langage du SAV. Rivet prend le chemin inverse et part du métier de l’intervention.

Pourquoi ce projet

Reconstruire le SaaS que j’utilise au quotidien m’oblige à comprendre ses choix de conception : modèle de données, permissions, multi-entreprise. C’est la différence entre configurer un outil et le concevoir.

Ce que fait Rivet

  • Tableau d’interventions : client, machine, technicien, statut et date.
  • Un seul compte pour plusieurs entreprises, avec choix de l’instance de travail.
  • Accès à une instance sur invitation uniquement.
  • Interface sobre, lisible par des techniciens en déplacement.

Technos

  • HTML
  • CSS
  • JavaScript
  • Supabase Auth
  • Supabase Postgres
  • GitHub Pages

Les données de chaque entreprise restent cloisonnées dans son instance.
