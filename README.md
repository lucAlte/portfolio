# Luc Alfonsi, product builder

Portfolio personnel : projets (RideDeck, Rivet), expériences (Lefort, Callio), compétences et CV.

Site statique en HTML, CSS et JavaScript, sans framework ni étape de build. Tous les fichiers sont à la racine.

| Fichier | Rôle |
| --- | --- |
| `index.html` | Contenu et visuels (maquettes en SVG) |
| `style.css` | Mise en page |
| `script.js` | Anneau animé du hero, machine à écrire, recherche dans la page |
| `inter-latin.woff2` | Police Inter, auto-hébergée |
| `callio-jeu-ecriture.png` | Visuel Callio |
| `CV-Luc-Alfonsi.pdf` | CV téléchargeable |

## Mise en ligne avec GitHub Pages

1. Déposer tous les fichiers à la racine du dépôt.
2. Settings > Pages > Source : `Deploy from a branch`, branche `main`, dossier `/ (root)`.
3. Le site est publié sur `https://<utilisateur>.github.io/<depot>/`.

Pour mettre à jour le CV, remplacer `CV-Luc-Alfonsi.pdf` en gardant le même nom.
